# Triage labels

The skills speak of five triage roles. With local files the label is the ticket's `Status:` line.

| Role in mattpocock/skills | `Status:` in loadout | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to look at it |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, an agent can do it alone |
| `ready-for-human` | `ready-for-human` | Needs a person (the live registry, a host, secrets) |
| `wontfix` | `wontfix` | Will not be done |

`done` closes a ticket.
