# Set up loadout

Install the CLI and sign in with `loadout login`. Your AI tool then gets the team's agents and skills.

```quiz
Where do the team's agents land after loadout login?

- [ ] In the repository you are in
  Agents live with the tool, a repository only holds your code.
- [x] In your AI tool, for every project
  Right. loadout installs into the tool, not into a repository.
```
